# Statistikkprodukt og metode i Nav
Library of statistical methods and helper functions to create statistical products.

R-pakken inneholder funksjoner for å koble til database, hente data, og kjøre prikkerutine (anonymisering) på data. Hensikten er å ha kvalitetssikrede fellesrutiner og arbeidsmetoder for produsering av statistikkprodukter. 

Prikking.R er statistikernes funksjon som benyttes med en fastsatt rutine.
https://confluence.adeo.no/spaces/navdvh/pages/852298026/Prikking+-+GaussSuppression 

dvh_prikking.R er datavarehusets funksjon for å prikke data gjennom en fast metode.
https://confluence.adeo.no/spaces/navdvh/pages/860129264/Prosedyre+-+Smale+aggregater

Støttefunksjonene db_connect.R og hent_data.R muliggjør en enklere datainnlast i R for statistikerne.
